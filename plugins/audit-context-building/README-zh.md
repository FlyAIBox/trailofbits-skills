# 审计上下文构建 (Audit Context Building)

在漏洞挖掘之前，通过超细粒度的代码分析构建深层架构上下文。

**作者：** Omar Inuwa

## 适用场景

当您需要以下能力时使用此技能：
- 在安全审计之前对代码库建立深刻的理解
- 建立自下而上的理解，而不是基于高层的猜测
- 减少复杂分析过程中的幻觉和上下文丢失
- 为威胁建模或架构审查做准备

## 功能介绍

此技能控制 Claude 在审计的上下文构建阶段的思维方式。激活后，Claude 将：

- 执行**逐行/逐块**的代码分析
- 在微观层面应用**第一性原理**、**5个为什么 (5 Whys)** 和 **5个如何 (5 Hows)**
- 构建并维护一个稳定、清晰的心智模型
- 识别不变量、假设、流程和推理隐患
- 跟踪跨函数和外部调用的流程，并进行完整的上下文传播

## 核心原则

这是一个**纯粹的上下文构建**技能。它**不**负责：
- 识别漏洞
- 提出修复建议
- 生成概念验证 (PoC)
- 分配严重程度或影响

它的存在仅为了在漏洞挖掘阶段之前建立深层的理解。

## 安装

```
/plugin install trailofbits/skills/plugins/audit-context-building
```

## 阶段

1. **初步定位** - 映射模块、入口点、参与者和存储
2. **超细粒度函数分析** - 带有跨函数流跟踪的逐行语义分析
3. **全局系统理解** - 状态/不变量重构、工作流映射、信任边界

## 防幻觉规则

- 绝不为了迎合早期的假设而歪曲证据
- 当出现矛盾时，显式地更新模型
- 避免模糊的猜测；使用“不清楚；需要检查 X”
- 不断进行交叉引用以保持全局一致性

## 相关技能

- `issue-writer` - 在构建上下文后编写发现
- `differential-review` - 使用上下文构建进行基线分析
- `spec-compliance` - 将理解的行为与文档进行比较
