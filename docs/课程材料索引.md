## 💡 核心方法论

### 识别可Skill化的场景(5问法)
1. ✅ 重复性高?(每天/每周都做)
2. ✅ 标准化强?(有明确的最佳实践)
3. ✅ 知识密集?(需要查很多文档)
4. ✅ 容易出错?(人工检查会遗漏)
5. ✅ 低创造性?(主要是机械性工作)

### Fail-Safe原则
```
❌ Fail-Open: 配置错误 → 使用不安全默认值 → 安全漏洞
✅ Fail-Safe: 配置错误 → 拒绝启动 → 强制修复 → 安全运行
```

### 安全6原则
1. 人工审核门控 - AI是建议者,人类是决策者
2. 敏感数据隔离 - 不让AI接触生产敏感数据
3. 最小权限原则 - AI只能访问最小权限
4. 审计日志 - 所有AI操作可追溯
5. 渐进式部署 - 从小范围试点开始
6. 故障降级方案 - AI不可用时系统仍能工作
