# Trail of Bits Skills - 快速入门指南

> 5 分钟快速上手 Trail of Bits Skills

## 🚀 三步开始使用

### 1. 添加技能市场

```bash
/plugin marketplace add trailofbits/skills
```

### 2. 浏览并安装

```bash
/plugin menu
```

### 3. 直接使用

向 Claude 描述您的需求，例如：

```
"扫描这个 Solidity 合约的安全漏洞"
"分析这段代码的时序侧信道"
```

## 🎯 推荐学习路径

### 第 1 天：基础入门

1. **安装技能市场**
   ```bash
   /plugin marketplace add trailofbits/skills
   ```

2. **尝试第一个技能**
   ```bash
   /plugin install trailofbits/skills/plugins/ask-questions-if-underspecified
   ```
   
   测试：给 Claude 一个模糊的需求，看它如何澄清

3. **安装 Python 开发工具**
   ```bash
   /plugin install trailofbits/skills/plugins/modern-python
   ```

### 第 2-3 天：静态分析

1. **安装静态分析工具包**
   ```bash
   /plugin install trailofbits/skills/plugins/static-analysis
   ```

2. **学习 Semgrep**
   - 运行基本扫描：`运行 Semgrep 扫描这个项目`
   - 创建自定义规则：`创建一个检测 SQL 注入的 Semgrep 规则`

3. **尝试 CodeQL**
   - `使用 CodeQL 分析这个项目`

### 第 4-5 天：智能合约（如果相关）

1. **安装合约安全工具**
   ```bash
   /plugin install trailofbits/skills/plugins/building-secure-contracts
   /plugin install trailofbits/skills/plugins/entry-point-analyzer
   ```

2. **实践审计流程**
   - 步骤 1：`分析这个合约的入口点`
   - 步骤 2：`使用 /secure-workflow-guide 扫描合约`
   - 步骤 3：`使用 /token-integration-analyzer 检查代币安全`

### 第 6-7 天：代码审查

1. **安装审查工具**
   ```bash
   /plugin install trailofbits/skills/plugins/differential-review
   /plugin install trailofbits/skills/plugins/insecure-defaults
   ```

2. **实践审查**
   - PR 审查：`审查这个 PR 的安全影响`
   - 配置审查：`检查不安全的默认配置`

### 第 8+ 天：高级技能

1. **加密安全**
   ```bash
   /plugin install trailofbits/skills/plugins/constant-time-analysis
   ```
   - `分析这个加密函数的时序侧信道`

2. **漏洞挖掘**
   ```bash
   /plugin install trailofbits/skills/plugins/variant-analysis
   ```
   - `找到类似这个漏洞的其他实例`

3. **深度审计**
   ```bash
   /plugin install trailofbits/skills/plugins/audit-context-building
   ```
   - `深度分析这个代码库，建立完整理解`

## 💡 实用技巧

### 1. 组合使用技能

**智能合约全面审计**：
```
1. 分析入口点
2. 使用 /audit-context-building 建立理解
3. 使用 /solana-vulnerability-scanner 扫描漏洞
4. 验证规范一致性
```

**代码审计流程**：
```
1. 使用 /audit-context-building 建立基线
2. 使用 /differential-review 审查变更
3. 使用 /variant-analysis 查找类似问题
4. 使用 /fix-review 验证修复
```

### 2. 自然语言交互

不需要记住复杂的命令，直接用自然语言描述：

✅ **好的示例**:
- "帮我审计这个智能合约的安全性"
- "检查这段代码是否有时序侧信道漏洞"
- "分析这个 PR 的安全影响"
- "扫描 Android APK 的 Firebase 配置"

❌ **不好的示例**:
- "运行工具" （太模糊）
- "检查漏洞" （太宽泛）

### 3. 指定目标范围

更精确的描述会得到更好的结果：

```
# 好：指定具体文件/目录
"扫描 src/protocol/ 目录的智能合约漏洞"

# 更好：指定具体问题
"检查 src/token.sol 中的重入漏洞和整数溢出"
```
