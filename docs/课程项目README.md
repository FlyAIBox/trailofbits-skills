## 🎓 课程简介

在AI时代,传统的研发流程面临着新的机遇与挑战。本课程通过**3个典型场景**,展示如何使用Claude Skill重构传统研发SOP,让AI和人类在新的工作流程中高效协作。

### 目标人群

- ✅ 1～2年编程经验的程序员
- ✅ 会基本编程(Python/JS/Go等)
- ✅ 掌握提示词基础
- ✅ 可能了解RAG等轻量AI学习资料
- ✅ AI落地经验尚浅或没有

### 课程特色

1. **即学即用**: 选择日常最常见的3个场景
2. **效果显著**: 时间节省70-90%,质量提升20-100%
3. **方法论导向**: 授人以渔,而非授人以鱼
4. **循序渐进**: 从简单到复杂,逐步深入
5. **安全可控**: 强调生产环境的安全保障

## 💡 核心方法论

### 识别可Skill化的场景(5问法)

```
1. ✅ 重复性高? (每天/每周都做)
2. ✅ 标准化强? (有明确的最佳实践)
3. ✅ 知识密集? (需要查很多文档)
4. ✅ 容易出错? (人工检查会遗漏)
5. ✅ 低创造性? (主要是机械性工作)

5个都是"是" → 非常适合Skill化!
```

### Fail-Safe原则

```
❌ Fail-Open: 配置错误 → 使用不安全默认值 → 安全漏洞
✅ Fail-Safe: 配置错误 → 拒绝启动 → 强制修复 → 安全运行

记住: 崩溃比不安全运行好!
```

### 安全6原则

1. **人工审核门控** - AI是建议者,人类是决策者
2. **敏感数据隔离** - 不让AI接触生产敏感数据
3. **最小权限原则** - AI只能访问最小权限
4. **审计日志** - 所有AI操作可追溯
5. **渐进式部署** - 从小范围试点开始
6. **故障降级方案** - AI不可用时系统仍能工作
